# web-scout-associate

> Colleague's scout subagent can read the web: cortex hands a 'scout: find X, cite evidence' brief to a scout child that runs on the associate seat when armed, drives the operator-installed WebGlass CLI through one curated read-only 'web' tool (search / page open-read-inspect-extract-links), and returns a digest with WebGlass evidence ids for cortex to judge — the same enumerated scout seat with one more read-only tool, never a per-turn model choice; no webglass on PATH = byte-identical.

## Audience

- The operator running cortex (Qwen3.8-27B) with the associate seat armed (`COLLEAGUE_ASSOCIATE_MODEL`=lobes → Nemotron 3.5 Lightning on Orin, addressed as the role name 'associate' through spark's gateway) who wants cited web facts without spending cortex reasoning turns per page

## Before → After

- Before: Colleague has no web access today: zero references to webglass / `web_fetch` / `web_search` under colleague/ (grep 2026-08-28); a scout child can only `read_file`/`list_dir`/`grep_search`/glob/`view_media`/deepthink/memory/finish (roles.py:106)
- After: After: on a lobes rig with webglass on PATH, 'colleague work' offers a 'web' tool; cortex hands 'scout: find X, cite evidence' to a scout child that (when `COLLEAGUE_ASSOCIATE_MODEL`=lobes) runs on the associate seat, fetches several pages in one parallel batch, and returns a digest citing WebGlass operation/evidence ids that land verbatim on the step trace; with no webglass on PATH or `COLLEAGUE_WEB`=0 every run is byte-identical to v1.64.0

## Why it matters

- Cortex spends a reasoning turn per page; the associate seat measured 17 s for a grep+paged-read survey and 9 s for a single-doc digest with thinking off (25 s / 61 s at low) on 2026-08-27 — web scouting is read-only fetch-and-summarise work, the associate profile exactly; today the seat sits idle because cortex never delegates (rows 45: zero associate calls)
