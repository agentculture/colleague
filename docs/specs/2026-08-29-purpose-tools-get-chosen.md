# purpose-tools-get-chosen

> Colleague's cortex chooses its purpose tools: the prompt no longer advertises delegation tools the acting seat does not hold, the raw alternatives that crowd the typed purposes out are removed where measurement says they should be, and every change lands as a pre-registered arm whose delegation rate is a tracked number
> instruction: verified by two artefacts: (1) a rendered pair - the acting seat's prompt and its offered tool list, showing no absent tool named and no offered purpose unnamed; (2) at least one completed docs/live-testing.md row whose delegation cell came from scripts/`compare_arms.py`, miss recorded as miss

## Audience

- The operator running cortex (Qwen3.8-27B) on the lobes-armed rig with `COLLEAGUE_ASSOCIATE_MODEL`=lobes and webglass on PATH, who shipped six purpose tools in v1.66.0 and has watched the model decline to call five of them across every measured run - and who has already decided (#435) that forcing delegation is not on the table, so the only remaining levers are what the model is told, what it is offered, and what the numbers say.

## Before → After

- Before: Before: the default prompt spends 174 words instructing the model to call subagent/subagents, which the acting seat does not hold, and 0 words on the six tools it does hold; the six purpose descriptions total 145 words, four carrying no steer and three carrying a steer-away clause; the only purpose prose that exists is a 49-word non-imperative armed-facts sentence on two of the six. Measured result: 0 purpose calls in 3 pre-registered runs plus 1 unregistered smoke (row 49), and delegation only where the raw alternative was removed (row 50).
  - instruction: recompute each number from source before writing the spec: word counts from colleague/prompttext.py and colleague/`purpose_schemas.py`, the delegation rate from docs/live-testing.md row 49
- After: After: a bare 'colleague work' prompt never names a tool the seat does not hold (option 1); the delegation rate for each option is a number in docs/live-testing.md rows 51+ with its brief committed beforehand and a miss written as a miss; the three levers are separable - prose-only, surface-only, and both - so the arm attributes the change to a cause instead of to the release.
  - instruction: the arm matrix in docs/live-testing.md has one row per lever with its own instrument cited (overlay sha256, env var, or allow-list diff), one shared brief, and one baseline; no row bundles two levers

## Why it matters

- 13-plus measured runs across rows 41-50 show cortex doing every survey itself; the associate seat is armed and idle. The one time it delegated (row 50) the raw alternative was gone. If prose cannot move the rate and surface composition can, that is a finding worth having as a number - it decides whether colleague's delegation design is a prompt problem or a surface problem, and #435's 'do not force it' means measurement is the only way to settle it.
  - instruction: the arc's closing doc names which lever moved the number and by how much, or states that none did - never 'inconclusive, needs more work' without the measured ratios beside it
